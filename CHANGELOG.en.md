# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.2] - 2026-05-30

### Changed

- Improved Markdown conversion process.

### Fixed

- Fixed localization omissions.

## [0.3.1] - 2026-05-30

### Added

- Added English documentation.
- Added localization for both Japanese and English.

## [0.3.0] - 2026-05-30

### Added

- Added English localization support.
- Dynamically updated the filename for preview display.

### Changed

- Improved UI and style adjustments.
- Changed tab titles to use filenames.
- Adjusted the position of the input and clear buttons, and changed the download button to an icon.
- Modified some error messages to warnings.

## [0.3.0-beta.1] - 2025-09-15

### Added / Changed

- Improved popup UI (simplified title, disabled URL input field).
- Removed unnecessary code and fixed links in `popup.ts`.

### Style

- Updated icons.

### Documentation

- Added and updated documentation.

## [0.2.0] - 2025-09-14

### Added

- Added functionality to convert web pages to Markdown.
- Improved the Markdown preview function and added a file download feature.

## [0.1.0] - 2025-09-14

### Added

- Added clear functionality for file name input.
