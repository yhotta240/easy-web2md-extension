1. Install this extension from the Chrome Web Store.
2. Open the web page you want to convert to Markdown.
3. Click the extension icon located in the Chrome toolbar.
4. A pop-up will open, and the page content will automatically be converted to Markdown.
5. Check the preview in the "Download" tab and rename the file if necessary.
6. Clicking the "Download" button will save the Markdown file.
