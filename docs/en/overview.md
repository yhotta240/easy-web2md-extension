This is a Chrome extension that allows you to convert and download the webpage you are currently viewing into Markdown format with a single click.

## Key Features

1. One-Click Conversion: Simply click the extension icon to instantly convert the displayed page content into Markdown.
2. Markdown Preview: Review the converted Markdown within the pop-up window for confirmation.
3. Automatic File Naming: The download file name is automatically set based on the domain name of the page.
4. Easy Download: Save your `.md` file immediately using the "Download" button in the preview screen.
