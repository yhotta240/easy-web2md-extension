1. Chromeウェブストアから本拡張機能をインストールします．
2. Markdownに変換したいWebページを開きます．
3. Chromeのツールバーにある拡張機能のアイコンをクリックします．
4. ポップアップが開かれ，自動的にページの内容がMarkdownに変換されます．
5. 「ダウンロード」タブでプレビューを確認し，必要に応じてファイル名を変更します．
6. 「ダウンロード」ボタンをクリックすると，Markdownファイルが保存されます．
